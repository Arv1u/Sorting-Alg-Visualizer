# Sorting Algorithms

##  Project Purpose

The purpose of this project is to learn about sorting algorithms, understand how they work, and gain hands-on experience implementing them.

I believe that actually implementing these algorithms will teach me more about their respective advantages and disadvantages than simply reading books or articles ever could.

##  AI Usage Tracking

Starting with this project, I'll keep track of how often I use AI in my projects.

The idea came from a bit of imposter syndrome: I sometimes question whether I've actually learned something or whether I'm capable of doing things on my own. By tracking my AI usage, I hope to get a better understanding of my own skills and progress.

To make this experiment meaningful, **only traditional learning resources are allowed**, such as:

- Documentation
- Forum posts
- Articles and tutorials
- Books

AI assistance is not allowed for learning or implementing the algorithms themselves, except for the instances explicitly documented below.
